ALTAKA-ALWATANIYAH — التطبيق الموحد والخادم (الحاسبة الأم)
==========================================================

1) الفكرة
---------
• تطبيق واحد لكل الموظفين باسم «الطاقة الوطنية» على: أندرويد، ويندوز، ماك، آيفون.
  يجمع: منظومة ERP (لموظفي الإدارات) + الحضور بالباركود والسيلفي + تطبيق الكشف + تطبيق
  التنفيذ + الإبلاغ عن المعوقات + رفع التقارير + الإشعارات.
• الخادم على «الحاسبة الأم» (ويندوز فقط) ويتكوّن من:
    - خادم منظومة ERP  (ALTAKA-ALWATANIYAH-ERP-Server.exe — مثبّت مسبقاً، لا يتغيّر)
    - بوابة التطبيق     (C:\ALTAKA-ALWATANIYAH\gateway — تُثبَّت بهذه الحزمة)
    - Cloudflare Tunnel (خدمة ويندوز)
• كل الأجهزة الأخرى (الحاسبات والهواتف، داخل الشركة وخارجها) تتصل بالحاسبة الأم عبر
  Cloudflare فقط — لا IP ثابت، ولا فتح منافذ في الراوتر، والاتصال مشفّر:
    https://app.altaka-field.com   ← بوابة التطبيق (الأدوات الميدانية)
    https://erp.altaka-field.com   ← منظومة ERP

2) تثبيت الخادم على الحاسبة الأم (مرة واحدة)
---------------------------------------------
  1. فك ضغط ALTAKA-ALWATANIYAH-Server-Windows.zip.
  2. زر الفأرة الأيمن على  install-server-windows.bat  ← «Run as administrator». يقوم بـ:
     - تثبيت Node.js إن لم يكن موجوداً.
     - نسخ البوابة إلى C:\ALTAKA-ALWATANIYAH\gateway ونقل بياناتها السابقة تلقائياً
       (الموظفون، المهام، السجلات) من مجلد البوابة القديم على سطح المكتب.
     - تشغيلها الآن ومع كل تشغيل لويندوز (مهمة مجدولة مخفية) بدل الاختصار القديم.
     - إبقاء خدمة Cloudflare Tunnel كما هي إن كانت تعمل، أو تثبيتها بالرمز (Token).
  3. في لوحة Cloudflare (Zero Trust ← Networks ← Tunnels ← النفق ← Public Hostname)
     تأكد من وجود الرابطين:
       app.altaka-field.com  ← النوع HTTP   ← localhost:8780
       erp.altaka-field.com  ← النوع HTTPS  ← localhost:5443
            ثم Additional application settings ← TLS ← «No TLS Verify» = ON
            (شهادة خادم ERP ذاتية التوقيع؛ Cloudflare يعطي الموظفين شهادة رسمية)
  4. التجربة من هاتف على بيانات الهاتف (بدون واي فاي):
       https://app.altaka-field.com/api/mobile/ping   ← تظهر بيانات فيها اسم الشركة
       https://erp.altaka-field.com                    ← تظهر شاشة دخول منظومة ERP
  ملاحظة أمان مهمة: بعد فتح erp.altaka-field.com تأكد أن «لوحة الخادم» (زر ⚙ ورمز الإعداد)
  لا تظهر من هذا الرابط وأن النظام يطلب اسم المستخدم وكلمة المرور. ولحماية إضافية يمكن تفعيل
  Cloudflare Access على erp.altaka-field.com (رمز يصل إلى بريد الموظف قبل فتح المنظومة).

  الربط بين ERP والبوابة يبقى داخلياً على الحاسبة الأم (http://127.0.0.1:8780) — لا تغيّره.

3) الصلاحيات حسب الاختصاص
---------------------------
  في منظومة ERP: الصلاحيات كما هي (الأدوار، والفصل بين الإدارات يطبّقه خادم ERP).
  في الأدوات الميدانية: لكل موظف ملف صلاحيات يحدده الخادم (لا الواجهة فقط):
    الإدارة العليا / مدير ....... كل الخصائص + ERP
    الإشراف والتنفيذ ............ الحضور، الكشف، التنفيذ، المعوقات، التقارير + ERP
    موظف كشف (التصميم) ......... الحضور، الكشف، المعوقات، التقارير
    فريق التنفيذ الميداني ....... الحضور، التنفيذ، المعوقات، التقارير
    مهندس ميداني ................ الحضور، الكشف، التنفيذ، المعوقات، التقارير
    موظف إدارة / مكتب ........... منظومة ERP فقط
  يُختار الملف تلقائياً من القسم والعنوان الوظيفي، ويمكن تغييره لأي موظف من لوحة البوابة
  (http://localhost:8780/admin ← الموظفون ← تعديل ← «الصلاحيات حسب الاختصاص»)، أو اختيار
  «مخصّص» وتحديد الخصائص واحدة واحدة. ويمكن لمنظومة ERP إرسال profile أو perms مع الموظف.

4) تثبيت التطبيق على الأجهزة
-----------------------------
  من صفحة الإصدارات في GitHub (Releases ← latest):
    أندرويد  : altaka-alwataniyah-field.apk  (يُثبَّت فوق النسخة القديمة وتبقى بياناتها)
    ويندوز   : altaka-alwataniyah-field-setup.exe  أو  altaka-alwataniyah-field-windows.zip
    ماك      : altaka-alwataniyah-field-mac-arm64.dmg (M1–M4)  أو  -mac-x64.dmg (Intel)
    آيفون    : افتح في Safari  https://app.altaka-field.com/app  ← مشاركة ← «إضافة إلى الشاشة الرئيسية»
  برنامج واحد فقط: منظومة ERP
    • التطبيق على كل الأجهزة يفتح منظومة ERP مباشرة: https://app.altaka-field.com/erp/
      (الآيفون: افتح الرابط في Safari ← مشاركة ← «إضافة إلى الشاشة الرئيسية»).
    • يدخل الموظف باسم المستخدم وكلمة المرور في ERP فقط — لا دخول آخر.
    • داخل ERP يظهر قسم «العمل الميداني» في القائمة الجانبية وبطاقاته في الشاشة الرئيسية
      (الحضور والمهام، الكشف، التنفيذ، المعوقات، التقارير) حسب صفة الموظف.
    • الموظف الجديد يُضاف في ERP على الحاسبة الأم (المستخدمون ← الوحدة التنظيمية والمنصب)،
      فتُحدَّد صفته الميدانية تلقائياً من وحدته ومنصبه عند أول دخول. لتغييرها يدوياً:
      http://localhost:8780/admin ← الموظفون ← «الصلاحيات حسب الاختصاص».
    • واجهة ERP على الهاتف: قائمة جانبية منزلقة (زر ☰) وبطاقات وجداول مناسبة للشاشة الصغيرة.

5) ما يجب معرفته
-----------------
  - يجب أن تبقى الحاسبة الأم مشغّلة ومتصلة بالإنترنت أثناء الدوام (خادم ERP يمنع السكون).
  - إذا انقطع الإنترنت يحفظ التطبيق الأعمال الميدانية في الجهاز ويرسلها عند عودة الاتصال؛
    أما منظومة ERP فتحتاج اتصالاً.
  - احتفظ بنسخة من: المستندات\ALTAKA-ALWATANIYAH-ERP-Server (مع data.key) و
    C:\ALTAKA-ALWATANIYAH\gateway\data على قرص خارجي.
